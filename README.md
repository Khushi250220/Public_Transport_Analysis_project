# 🚇 Public Transportation Performance & Route Analytics

## 📌 Project Overview

The **Public Transportation Performance & Route Analytics** project is an end-to-end data analytics project designed to analyze transportation operations, passenger demand, route performance, delays, cancellations, and vehicle utilization.

The project uses **Python for data cleaning and exploratory data analysis, MySQL for SQL-based business analysis, and Power BI for interactive dashboard development**.

The primary objective is to identify high-demand routes, underutilized routes, peak travel periods, operational inefficiencies, and areas where transportation capacity can be optimized.

---

## 🎯 Business Problem

Public transportation operators generate large amounts of operational data, but raw data alone does not provide actionable insights.

This project aims to answer key business questions such as:

- Which routes have the highest passenger demand?
- Which routes are underutilized?
- What are the peak travel hours?
- Which routes experience the highest delays?
- What is the cancellation rate?
- How efficiently is available transportation capacity being utilized?
- How does passenger demand change over time?
- Which routes require additional capacity?
- Which routes may require schedule or frequency optimization?

---

## 🎯 Project Objectives

- Analyze passenger demand across different routes.
- Identify peak and off-peak travel periods.
- Measure route utilization.
- Analyze delays and on-time performance.
- Evaluate trip cancellations.
- Compare weekday and weekend demand.
- Identify overloaded and underutilized routes.
- Develop actionable recommendations for transportation operations.
- Build an interactive Power BI dashboard for decision-making.

## 📂 Dataset

The project uses a simulated public transportation dataset containing **12,000 trip records** across **15 routes**.

The dataset covers transportation operations from **January 2025 to June 2026**.

### Main Dataset Columns

| Column | Description |
|--------|-------------|
| `trip_id` | Unique identifier for each trip |
| `route_id` | Unique route identifier |
| `route_name` | Transportation route |
| `date` | Trip date |
| `departure_time` | Scheduled departure time |
| `scheduled_arrival` | Scheduled arrival time |
| `actual_arrival` | Actual arrival time |
| `passengers` | Number of passengers |
| `capacity` | Vehicle passenger capacity |
| `trip_status` | Completed or Cancelled |
| `fare` | Fare per passenger |
| `distance_km` | Route distance |
| `delay_minutes` | Arrival delay |
| `utilization_rate` | Percentage of vehicle capacity utilized |
| `revenue` | Revenue generated by the trip |
| `day_of_week` | Day of the week |
| `month` | Month of the trip |
| `peak_hour` | Peak or Off-Peak classification |
